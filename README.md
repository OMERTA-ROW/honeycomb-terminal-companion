Keep unpublished; do not deploy, enable public sharing, charge subscriptions or connect paid services. Preserve requirements in a project specification and implementation checklist. Clearly distinguish working features from mocked interfaces and native-platform work that is not implemented. No actual customer passwords or remote host access in this initial preview. Create Honeycomb Terminal as separate product from Honeycomb Vault, Omni and Evolution. Canonical plan https://app.notion.com/p/403c1161030681c98771c23caa433198 . Responsive iPad/phone remote terminal experience, desktop companion planned for macOS Windows Linux; mobile goal iOS/iPadOS/Android. Install host companion/mobile app, sign in, approve pairing once, tap paired host to open/resume actual host shell with installed tools/files/permissions. No routine IP entry or connection commands. First preview: paired computers screen with accurate availability; pairing/connection flow, terminal screen, Instructions tab, keyboard accessory Escape/Control/Tab/arrows, customizable command/key shortcuts with command preview and destructive-action confirmation, touch selection/copy/paste and external keyboard support. Clearly label sample hosts, simulated pairing/terminal and commands; do not claim real execution or connection without actual companion/transport. Keep advanced settings out of ordinary setup. Secure authenticated pairing, encrypted transport, protected device keys, revoke devices, owner authorization mandatory. Persistent host sessions/reconnect after network drop where supported. Asleep/offline/permission/connection errors with actionable next step. Host must be awake/reachable. Local iPad execution/cloud compute separate, not assumed. Capture native companion and mobile packaging requirements and acceptance tests; choose first host feasibility before claiming universal support. Updates: tested patches staged at safe times preserving active sessions, rollback/recovery where supported; no automation activated. Proposed price $20/user/year across devices; device limits, relay/payment/support costs and margins unvalidated; no billing activation. No Honeycomb Vault advertising in Terminal (promotion is one-way from Vault to Terminal). Preserve complete spec/checklist and distinguish implementation vs prototype vs blocked. Test preview keyboard, touch layout, shortcuts, offline/revoked states and report actual results. No public deployment.
