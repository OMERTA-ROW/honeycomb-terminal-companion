## 2. Host persistent sessions via tmux (planned)

Companion attaches/re-attaches PTY to the same authorized session; network drop detaches client, not job. Test 30-second disconnect, same session/process ID, continuing job, offline/sleep, revoke-denies-reconnect, permission denial and host restart.
